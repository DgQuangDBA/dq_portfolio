# Portfolio — Phan Duy Quang (Database Administrator)

Website portfolio song ngữ Anh/Việt, tối ưu mobile. HTML/CSS/JS thuần.

## Cấu trúc
```
portfolio/
├── index.html   ← nội dung
├── style.css    ← giao diện
├── script.js    ← song ngữ EN/VI, menu, hiệu ứng
└── assets/
    ├── logo-pq.svg              logo PQ (favicon)
    ├── portrait_hero.png        ảnh chân dung (đã cắt viền)
    ├── logo_vbsp / hnx / ipvn / vinatti / onenet / ndc .png   logo khách hàng
    ├── og-image.png            ảnh share link
    ├── CV_PhanDuyQuang_EN.pdf  CV tiếng Anh
    └── CV_PhanDuyQuang_VI.pdf  CV tiếng Việt
```

## Chạy thử
M�� index.html bằng trình duyệt, hoặc chuột phải → Open with Live Server (VS Code).

## Sửa nội dung
- Chữ: sửa trong script.js (object content: content.en / content.vi).
- Link CV tự đổi theo ngôn ngữ đang chọn.
- Đổi ảnh hero: thay assets/portrait_hero.png.

## Deploy miễn phí
Kéo-thả cả thư mục vào https://app.netlify.com/drop → có link ngay.
Hoặc push GitHub → import vào vercel.com.
